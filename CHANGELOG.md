# Changelog

## 0.2.0 — 20.11.2026

- 📝 Beta: Lorelamp is still a beta. Please report what breaks as an issue
- 📝 Install: Lorelamp is not signed yet, so Windows SmartScreen warns on the first start. Click "More info", then "Run anyway"
  - `Lorelamp-0.2.0-setup.exe` installs the app for your Windows user; `Lorelamp-0.2.0-portable.exe` runs without installing. Both keep your data in `%APPDATA%\rp-app`, so an update keeps your characters and chats
  - `Lorelamp-0.2.0.apk` is the Android remote (Android 7 or newer, 64-bit ARM). It installs over 0.1.0
  - `SHA256SUMS.txt` has the checksum of every file
- 🎉 Greetings: A card's alternate greetings become variants of the first message in a new chat, so you can pick the opening you like
- 🎉 Chat look: New layout "Wide messenger" (the character's messages on the left edge, yours on the right) and many more look settings, for the whole app under Settings → Chat or per chat under "Appearance of this chat"
- ⚡️ Reply length: The reply length in Settings → Expert is now a real limit. A reply is never longer than what you set, and it ends on a complete sentence with no speech or action left open. Before, the model often wrote past the setting
- ⚡️ Long chats: When a chat no longer fits into the model's context, the oldest messages after the first one are left out in larger steps, so replies stay fast. If even the character card does not fit, the chat says so instead of failing silently
- ⚡️ Chat: Going past the last variant of a reply writes a new one. Editing your last message offers "Save and reply again"
- ⚡️ Start and navigation: Clearer first steps (model, character, your name, first chat), a simpler model setup, and "Connect a phone" moved up in the sidebar
- ⚡️ Overviews: The start page and the chat lists quote the character's last line instead of your own
- ⚡️ Character page and card builder: "New chat" opens the chat right away, the card builder guides you until name and description are filled in, and the export dialog says when a character has no picture
- 🦺 Tablet: Larger touch targets in the chat look settings and the card builder
- 🏗️ Removed: scene pictures

## 0.1.0

- 📝 Beta: this is the first public version. Some things will still be rough, so please report what breaks as an issue
- 📝 Install: Lorelamp is not signed yet, so Windows SmartScreen warns on the first start. Click "More info", then "Run anyway"
  - `Lorelamp-0.1.0-setup.exe` installs the app for your Windows user with a Start menu entry; `Lorelamp-0.1.0-portable.exe` runs without installing
  - Both keep your data in the same place (`%APPDATA%\rp-app`), so you can switch between them
  - `SHA256SUMS.txt` has the checksum of every file, so you can check a download with `Get-FileHash`
  - Tested on Windows 11 (64-bit) only. The app needs Microsoft Edge WebView2, which Windows 11 already has; the installer fetches it when it is missing
- 📝 Android: `Lorelamp-0.1.0.apk` (Android 7 or newer, 64-bit ARM) is signed but not in a store, so Android asks you to allow installing from this source. The QR scanner needs Google Play services; without a camera, type the code instead
- 📝 Phone: The first time you switch on Wi-Fi access, Windows asks about its firewall. Allow it, or phones cannot reach the PC
- 📝 Models: No model and no llama.cpp come with the app. "Set up engine" in the first steps scans your PC and downloads the matching official llama.cpp build, then suggests models that fit; you can also use GGUF files you already have
- 📝 Known limits: Background pictures you upload and scene pictures are not part of backups. The Wi-Fi access works over plain HTTP, so use it at home only
- 🎉 Languages: The whole interface in English, Deutsch, Español and Русский, picked in the first-start tour or under Settings → General. The characters answer in that language, whatever language their card is written in
- 🎉 First start: A short tour through language, model, a first character, your name and the first chat. Every step can be skipped, and Settings → General starts it again
- 🎉 Characters: Import character cards (PNG and JSON, V1, V2 and V3), many at once: drag them in, pick files, drop a ZIP or paste with Ctrl+V
  - Paste a link: Chub and RisuRealm cards come in directly, other pages work when they offer a card file. Sites whose rules forbid programs open in your browser so you can save the card yourself
  - A linked card shows a preview before it is saved; cards you already have are recognised
  - A character's or persona's picture can also come from a link. The PC fetches it, with the same network checks as the card link
- 🎉 Card builder: Build a character from an idea in one sentence, with genre, tone, traits and setting. The local model drafts each field on request (name, description, scenario, first message, examples, tags), you change anything, and a preview shows the library card, the first message and the token cost before you save. You can start from a copy of an existing character; lorebook entries and export as PNG or JSON are included
- 🎉 SillyTavern: Finds your SillyTavern folder and takes over the characters, personas and chats you pick, with every reply variant (swipe)
- 🎉 Chat: Replies appear while the model writes, with Stop, Edit, Rewind (with Undo), Branch off into a new chat and switching between reply variants
- 🎉 Chat: Regenerate a reply as a new variant, or let it continue from where it stopped
- 🎉 Chat: Search inside a chat with Ctrl+F; the head shows how much of the context is used
- 🎉 Chat look: Font, size, line spacing and width, book, bubble, messenger or dense layout, a large character portrait, and colours for speech and actions. The messenger layout puts the character on the left and you on the right. Settings → Chat sets the look of all chats with a live preview, and each chat can have its own
- 🎉 Backgrounds: Your own picture, or one of 16 ready-made ones (tavern, library, forest, space station, harbour and more), for a chat or for all chats with a character
- 🎉 Scene as a picture: A button at a message paints its scene through your own Codex access. It is off until you switch it on under Settings → Chat. The local model only sorts the scene into fixed options, and the painting order is built from their wording, so no chat, card or persona text leaves the PC.
- 🎉 Personas: Describe who you play (name, pronouns, appearance, personality, background). One is active everywhere, a chat or a character can use another
  - "You in this story" shows where a card describes you differently from your persona, and which one wins
- 🎉 Cards: Edit a character's card, or keep a separate copy of it for one chat. Export cards as PNG or JSON (V2, V3) and personas in SillyTavern's format
- 🎉 Characters: Poster, compact or list view, search, your own tags, favourites, select many at once (drag a frame, Shift+click, Ctrl+A), delete with Undo. Large libraries stay quick: card checks are cached and cards off screen are not drawn
- 🎉 Home: Five start layouts to choose from, with the model status, first steps and a one-click new chat
- 🎉 Settings: The General tab sets the language, the send key (Enter or Ctrl+Enter), what the app opens with, asking before deleting or rewinding, how long Undo stays, the backup rhythm (daily, weekly, off), starting with Windows and the data folder
- 🎉 Models: A catalog of 55 roleplay models with suggestions for your PC, from CPU-only to 24 GB graphics cards (NVIDIA, AMD, Intel)
  - Describe in one sentence what you want to do with the model, and the suggestions and settings follow it
- 🎉 Models: Downloads from Hugging Face pause, resume, carry on after a restart and are checked by SHA-256
- 🎉 Models: Uses GGUF files from the app's folder, your own folders and LM Studio (read only)
- 🎉 Models: "Find the best setting" measures context size, cache type and offloading on your PC and applies the result with one click
- 🎉 Models: Simple and expert settings with every sampler and start option. The app starts llama.cpp itself, restarts it after a crash and can unload the model after a while to free the graphics card. A model server Lorelamp started always ends with it, also after a crash or when it is ended in the Task Manager
- 🎉 Engine: "Set up engine" in the first steps downloads, checks and tests the llama.cpp build that fits your PC, then leads on to the model suggestions. A Vulkan build, or AMD without the ROCm runtime, is only offered as a choice
- 🎉 Backups: Daily, weekly and before every database update, plus your own; restore keeps a safety copy first. The backup folder has a size limit you choose
- 🎉 Android: The Lorelamp app is a remote for Lorelamp on your PC: scan the QR code or type a code, then it shows the PC's interface while model, characters, chats and downloads stay on the PC. Its start page speaks English, German, Spanish and Russian, following the phone's language. It remembers the PC and offers to retry or reconnect when the PC is off
- 🎉 Phone: Settings → Phone switches Wi-Fi access on and off while the app runs, with a QR code, a 6-digit code (10 minutes, a new one after 5 wrong tries), the address to type and "Disconnect all phones"
  - The app finds the PC in the Wi-Fi by itself; if not, enter the address and the code
  - Without the app, open the QR code with the phone's camera and add the page to the home screen to start it like an app
  - On the phone the back key closes search and sheets
- 🎉 Tablet: Its own layout on tablets, with a navigation rail, the character and its chats beside the story, and swipes for reply variants
- 🎉 Search: Ctrl+K finds characters, chats, messages and settings, even from a rough description
- 🎉 Themes: Six themes, "Graphite" (dark) by default and "Paper" (light)
- 🎉 Icon: A flame with an open book in it, for the window, the installer, the Android app and the browser tab
- 🎉 Logs: An activity log for finding problems; it never stores message text, card text or character names
- 🦺 Safety: Actions that belong to the PC (models, engines, downloads, backups, the phone access) are refused from phones. Start options for llama.cpp pass an allowlist. Wrong pairing codes lock out the address that sent them. Every answer carries security headers, and the desktop window only opens pages of the app
- 🦺 Safety: The Android app asks before a `lorelamp://` link connects it to a PC. Imports keep to one memory budget with limits for ZIPs and pictures. A message can hold at most 64,000 characters
